# Crucible Docs

Crucible is a workflow plugin for Obsidian. It combines note materialization, templated capture, linting, attachment localization, AI agents, chained commands, ingestion trackers, and vault search.

## Guides

- [Command reference](commands.md): all static command groups, plus how dynamic shortcut, capture, chain, and agent commands appear.
- [Materialize and templates](materialize-and-templates.md): daily, weekly, monthly note creation and shared template variables.
- [Captures, chains, and agents](captures-chains-agents.md): capture commands, AI providers, agents, chain steps, and response passing.
- [Lint and localize](lint-and-localize.md): frontmatter cleanup, word counts, transcript cleanup, attachment localization, and repair commands.
- [Orchestration](orchestration.md): queue behavior, workflow jobs, triggers, schedules, and settings.
- [Tracked sources](tracked-sources.md): Tracked Blogs and YouTube registry note formats, required columns, optional columns, and accepted values.
- [Ingestion dashboard](ingestion-dashboard.md): dashboard sections, actions, ignored IDs, and orphan cleanup behavior.
- [Search companion](search-companion.md): local search service setup and API contract.
- [Local inference](local-inference.md): choosing and configuring a local embedding/reranking server, and the failure modes that produce no error.
- [GBrain evaluation](gbrain-evaluation.md): what was adopted, what was rejected, and why, from evaluating the GBrain retrieval/graph/synthesis platform.

## Quick Paths

- To create configured daily, weekly, or monthly notes, see [Materialize and templates](materialize-and-templates.md).
- To build repeatable workflows from multiple commands, see [Captures, chains, and agents](captures-chains-agents.md).
- To set up blog or YouTube intake, see [Tracked sources](tracked-sources.md) and [Orchestration](orchestration.md).
- To understand command names shown in Obsidian, see [Command reference](commands.md).
